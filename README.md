# course-datasets

## Recommender systems lab: Amazon Video Games

The Fall 2026 lab uses the two compressed files in
[`amazon-video-games/raw-v1`](amazon-video-games/raw-v1). They contain 185,798
review records and metadata for 39,648 products. Total download size is 70.3 MB.
See the directory README for source attribution and the manifest for SHA256 hashes.
